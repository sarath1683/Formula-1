# Downforce Notebook

A dark, interactive study website built while reading *Competition Car Aerodynamics* (3rd edition) by Simon McBeath.

- Home page: a 10-turn circuit map (after the Red Bull Ring). Each turn opens a chapter.
- Chapter 1: interactive timeline 1956–2011, grip lab, quiz.
- Glossary that grows with each chapter.

Live site (GitHub Pages): https://sarath1683.github.io/Formula-1/

The whole site is the single file `index.html`.
